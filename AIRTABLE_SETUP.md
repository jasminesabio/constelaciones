# Airtable Setup Guide

Before running the seed script, you need to create the Airtable base and tables.

## Step 1: Create a new Airtable Base

1. Go to [Airtable](https://airtable.com)
2. Create a new base called "Constelaciones"
3. Note the base ID from the URL (it starts with `app...`)

## Step 2: Create Tables

You need to create 4 tables with the following schemas:

### Table 1: People

| Field Name | Field Type | Notes |
|------------|------------|-------|
| id | Single line text | Primary field |
| name | Single line text | Person's name |
| home_city | Single line text | e.g., "Boston, MA" |
| avatar_url | URL | Optional profile photo |
| contact_handles | Single line text | e.g., "@jasmine on IG" |
| last_updated | Date | Auto-filled |

### Table 2: Trips

| Field Name | Field Type | Notes |
|------------|------------|-------|
| id | Single line text | Primary field |
| person_id | Single line text | Linked to People (optional) |
| person_name | Single line text | Person's name |
| destination | Single line text | e.g., "Madrid, Spain" |
| start_date | Date | Trip start |
| end_date | Date | Trip end |
| event_tag | Single select | Options: festival, conference, vacation, work, other |
| status | Single select | Options: pending, approved, rejected |
| notes | Long text | General notes |
| flight_to | Long text | JSON: flight details arriving |
| flight_from | Long text | JSON: flight details departing |
| accommodation | Long text | JSON: where staying |
| events | Long text | JSON array: activities/events |
| shared_with | Single line text | Comma-separated names |
| last_updated | Date | Auto-filled |

### Table 3: Tickets

| Field Name | Field Type | Notes |
|------------|------------|-------|
| id | Single line text | Primary field |
| event_name | Single line text | e.g., "Burning Man 2026" |
| event_date | Date | Event date |
| event_location | Single line text | City, State |
| seller_id | Single line text | Person selling |
| asking_price | Single line text | e.g., "1500 MXN or trade" |
| status | Single select | Options: available, claimed, sold |
| notes | Long text | Details about the ticket |
| last_updated | Date | Auto-filled |

### Table 4: Submissions

| Field Name | Field Type | Notes |
|------------|------------|-------|
| id | Single line text | Primary field |
| type | Single line text | e.g., add_trip, edit_trip |
| submitter_name | Single line text | Who submitted |
| submitter_contact | Single line text | How to reach them |
| payload | Long text | JSON of submitted data |
| status | Single select | Options: pending, approved, rejected |
| admin_notes | Long text | Your review notes |
| created_at | Date | Auto-filled |
| updated_at | Date | Auto-filled |

## Step 3: Get your API Key

1. Go to https://airtable.com/create/tokens
2. Create a new personal access token
3. Give it these scopes:
   - `data.records:read`
   - `data.records:write`
   - `schema.bases:read`
4. Add access to your "Constelaciones" base
5. Copy the token (starts with `pat...`)

## Step 4: Update your .env file

Update your `.env` file with:

```
AIRTABLE_BASE_ID=appXXXXXXXXXXXXXX
AIRTABLE_API_KEY=patXXXXXXXXXXXXXXXXXX...
CONSTELACIONES_PASSWORD=mexicocity
NOTIFICATION_EMAIL=jasmine.operations@gmail.com
```

## Step 5: Run the seed script

```bash
npm run seed
```

This will populate your Airtable with Jasmine and Dan's travel data!

## Notes

- The `id` field in each table can be auto-generated by Airtable or you can use a formula like `RECORD_ID()`
- For dates, use the ISO format: `YYYY-MM-DD`
- JSON fields store structured data as text that the app parses
- You can manually add/edit records in Airtable at any time
